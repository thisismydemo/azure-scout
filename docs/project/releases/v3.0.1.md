# AzureScout v3.0.1

Version 3.0.1 corrects tenant scoping in Azure context switches and preserves the
guided wizard for interactive diagnostic invocations.

## Fixed

- Subscription context switches now explicitly bind the requested tenant, including
  permission auditing, VM quota collection, Defender/security sweeps, and Advisor ingestion.
- An interactive `Invoke-AzureScout -Debug` invocation now opens the guided wizard; common
  parameters no longer look like product choices.

## Verification

- Focused Pester coverage verifies context switches and restores carry the tenant.
- A tenant-scoped live run completed with 174 declarative collectors, zero collector failures,
  no unrelated-tenant authentication attempts, and a generated Excel report.

See [v3.0.0](./v3.0.0.md) for the engine-rebuild architecture and migration notes.
