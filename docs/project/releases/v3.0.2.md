# AzureScout v3.0.2

Version 3.0.2 removes two permanently retired Application Insights API paths and makes
storage service-property enrichment subscription-safe.

## Fixed

- Continuous Export and Work Item Config child-resource calls are no longer made.
- Storage blob and file service-property calls enter the storage account's subscription;
  a failed context switch produces contained warnings rather than requests in the wrong scope.

## Verification

- App Insights child-resource regression suite: 9 passed.
- Storage enrichment regression suite: 5 passed.
