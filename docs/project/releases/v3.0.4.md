# AzureScout v3.0.4

Version 3.0.4 corrects a production VM-reporting regression discovered by a Gallery-installed
live-tenant run.

## Fixed

- The `Compute/VirtualMachine` collector accepts repeated `MemoryGB` capability values from the
  Compute SKU payload and calculates memory usage from one usable value.

## Verification

- The focused declarative regression contract reproduces the repeated-value payload and passes.
- The release requires a fresh Gallery-installed live-tenant run with all 174 collectors before
  the associated AB#5638 runtime work is resolved.
