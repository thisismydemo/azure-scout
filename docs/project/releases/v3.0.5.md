# AzureScout v3.0.5

Version 3.0.5 corrects the remaining VM-reporting regression found by Gallery-installed
live-tenant verification.

## Fixed

- Cost Management nested rows are unwrapped to their amount cell before numeric conversion in
  the `Compute/VirtualMachine` collector.

## Verification

- The focused declarative regression contract reproduces both repeated Compute SKU capability
  values and a nested Cost Management row.
- A clean PowerShell Gallery 3.0.5 install completed a live-tenant `-Scope ArmOnly` run on
  29 July 2026. The deterministic processing phase ran all 174 declarative collectors with
  0 failures and produced an Excel workbook with 1,121 rows.
